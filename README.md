# Discord 煽りツッコミBOT

指定ワードには必ず返信し、それ以外の発言はGemini API または Ollama が返信すべきか判断します。AI判断と返信生成は1回のAPI呼び出しで行います。10秒の連投制限とBOT・Webhook除外はどちらにも適用されます。

## 起動

Python 3.12以降とプロジェクトの依存パッケージが必要です（`uv sync`）。
Discord Developer Portal で Message Content Intent を有効にし、BOTにチャンネル閲覧・メッセージ送信・メッセージ履歴の閲覧権限を付けてください。

既存の `.env` に以下を設定してください。キーやトークンは公開しないでください。

```dotenv
DISCORD_TOKEN=DiscordのBOTトークン
AI_PROVIDER=gemini
GEMINI_API_KEY=GeminiのAPIキー
GEMINI_MODEL=gemini-2.5-flash-lite
```

`uv run python bot.py` で起動します。
Gemini使用時は、連投制限内のテキスト発言を指定ワードの有無によらずGoogleのAPIに送ります（固定返信は除く）。起動・再接続時のログで使用中のAIを確認できます。
速度優先の初期モデルは `gemini-2.5-flash-lite` です。2.5 Flash系では思考を無効にします。利用モデルは `GEMINI_MODEL` で変更できます。既存の環境変数に設定がある場合はそちらが優先されます。

Ollamaを使う場合は `AI_PROVIDER=ollama`、`OLLAMA_MODEL=llama3.2:3b` に設定し、Ollamaを起動してモデルをダウンロードしてください。
`AI_PROVIDER` 省略時はGeminiキーがあればGemini、なければOllamaを使います。`GOOGLE_API_KEY` も利用できます（`GEMINI_API_KEY` を優先）。

## 反応ワードと口調

`reactions.json` を編集してBOTを再起動すると反映されます。

```json
{
  "@everyone": null,
  "OW": "その自信だけはランク高いねｗ",
  "valo": null
}
```

- `null`：必ず返信するワードです。AIが本文を生成し、失敗・見送り時は定型文を返します。
- 文字列：その固定返信を即座に使います。APIは呼びません。
- 複数一致した場合はファイルの上にあるワードを優先します。
- 日本語は部分一致、英数字だけのワードは英単語の途中での一致を除外します（`OW` は `tomorrow` に反応しません）。英単語の境界は英数字とアンダースコアで判定します。
- 全角英字・英字の大小・ひらがな／カタカナの違いを吸収します。

AIの口調は `bot.py` の `SYSTEM_PROMPT` で調整できます。返信は最大60文字、同じ人・同じチャンネルでのAI判定は10秒に1回です（見送り・失敗も含む）。
他のBOTやWebhookの投稿には反応せず、返信からのメンション通知も無効です。
指定ワードを含まない発言では、普通のゲーム募集・相談や真面目な質問には返信せず、悪口や冗談の煽りなどにツッコむよう指示しています。判断対象はその発言のみで、会話履歴は送りません。
指定ワードを含まない発言は、AIの見送り・APIエラー・15秒のタイムアウト・空返答・不正なJSONの場合に返信しません。指定ワードを含む発言は、これらの場合にも定型文で返信します。

待ち時間の上限は `.env` の `AI_TIMEOUT_SECONDS=15` で変更できます（Discord送信時間は別）。AI返信処理の所要秒数はログに記録します。

返信がない場合は、直前の `AI判断` やエラーログを確認してください。HTTP 400/401/403 はキーや設定、404 はモデル、429 はAPI利用制限を確認します。タイムアウトと空返答も別々にログへ記録します。
